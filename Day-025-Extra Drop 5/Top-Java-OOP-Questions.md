# 🎓 Top Java OOP Interview Questions

## 1. What is Object-Oriented Programming?

Object-Oriented Programming (OOP) is a programming paradigm that organizes code using objects and classes.

Its four main principles are:

- Encapsulation
- Abstraction
- Inheritance
- Polymorphism

---

## 2. What is a Class?

A class is a blueprint for creating objects.

Example:

```java
class Student {

}
```

---

## 3. What is an Object?

An object is an instance of a class.

Example:

```java
Student s = new Student();
```

---

## 4. What is Encapsulation?

Encapsulation means wrapping data and methods into a single unit while restricting direct access using private fields.

---

## 5. What is Inheritance?

Inheritance allows one class to acquire properties and methods of another class using the `extends` keyword.

---

## 6. What is Polymorphism?

Polymorphism means "many forms."

Types:

- Compile-time (Method Overloading)
- Runtime (Method Overriding)

---

## 7. What is Abstraction?

Abstraction hides implementation details and only shows essential functionality.

Implemented using:

- Abstract classes
- Interfaces

---

## 8. Difference between Abstract Class and Interface?

| Abstract Class                            | Interface                                                                 |
| ----------------------------------------- | ------------------------------------------------------------------------- |
| Uses abstract keyword                     | Uses interface keyword                                                    |
| Can have constructors                     | Cannot have constructors                                                  |
| Can contain abstract and concrete methods | Primarily contains abstract methods (default/static methods also allowed) |
| Supports single inheritance               | Supports multiple interface implementation                                |

---

## 9. What is Method Overloading?

Same method name with different parameter lists.

---

## 10. What is Method Overriding?

Redefining a superclass method in a subclass.

---

## 11. What is Dynamic Method Dispatch?

It is runtime method selection based on the actual object type.

---

## 12. Why is Java called an Object-Oriented Language?

Because Java uses classes and objects to model real-world entities and supports the four pillars of OOP.

---

# ⭐ Interview Tip

Don't memorize definitions.

Understand the concepts and explain them using real-life examples.
