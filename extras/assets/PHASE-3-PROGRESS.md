# 🏗 Major Milestones

## 🟢 Thinking in Objects

One of the biggest transitions in this phase was moving from writing procedural code to thinking in terms of **objects and relationships**.

Instead of asking:

> "Which function should I write?"

I started asking:

> "Which object should be responsible for this task?"

This shift is fundamental to becoming a software developer.
