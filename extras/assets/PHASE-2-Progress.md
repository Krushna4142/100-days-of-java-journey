# 🎯 Phase Goal

Phase 2 was focused on strengthening **problem-solving skills** by learning how Java handles data, functions, strings, arrays, searching, sorting, and algorithm efficiency.

Unlike Phase 1, which introduced Java syntax, this phase emphasized **thinking logically before writing code**.

The objective was to develop a mindset for solving programming problems instead of simply learning language features.

# 📝 Challenges I Faced

Some concepts were more difficult than others.

Examples include:

- Understanding recursion flow
- Tracing nested loops
- Comparing sorting algorithms
- Remembering algorithm complexity
- Working with 2D arrays

Rather than skipping these topics, I practiced them repeatedly until the logic became clearer.

---

# 🛠 Debugging Lessons

Some valuable lessons from this phase:

- Read compiler errors carefully.
- Dry-run algorithms before coding.
- Print intermediate values while debugging.
- Test edge cases instead of only ideal inputs.
- Focus on understanding the logic before optimizing the solution.
